Cara menjalankan program :
1. Akses melalui link : http://localhost/TEST_SIMRS/pasien.php.
2. Pada halaman tersebut berisi data pasien, user dapat melakukan proses create, update, dan delete data pasien.
3. Untuk melakukan penambahan data pasien, user dapat menekan button "Tambah Pasien". Maka sistem akan menampilkan form penambahan pasien yang berisi field yang harus diinput. Setelah semua field terisi, klik button "Simpan" untuk menyimpan data, sistem akan otomatis menyimpan data ke tabel SQL.
6. Untuk melakukan perubahan data pasien, user dapat menekan button "Edit" pada kolom pasien paling kanan. Kemudian sistem akan menampilkan form perubahan pasien yang berisi field yang sudah terisi data sesuai tabel. User dapat melakukan perubahan terhadap field yang akan diupdate, klik button "Update" untuk menyimpan data, sistem akan otomatis menyimpan data ke tabel SQL.
6. Untuk melakukan penghapusan data pasien, user dapat menekan button "Delete" pada kolom pasien paling kanan. Kemudian sistem akan menampilkan pop up konfirmasi penghapusan data. Jika sudah memilih opsi "Ya" pada halaman konfirmasi, maka row data pada tabel akan otomatis terhapus.
